ife Tracker App

A personal productivity and self-improvement application built with Flutter.

The app helps users track:

Gym progress
Daily expenses
Study sessions and productivity
Personal habits and routines
Features
Gym Tracking
Track workouts and exercises
Log sets, reps, and weights
Monitor fitness progress over time
Expense Tracking
Add daily expenses
Categorize spending
Track monthly budgets and habits
Study Tracking
Log study sessions
Track study hours
Monitor consistency and productivity
Productivity & Habits
Daily habit tracking
Progress statistics
Personal improvement monitoring
Tech Stack
Frontend: Flutter
Language: Dart
State Management:  GetX
